# AKIM AI — интерфейс

Next.js App Router, React, TypeScript, Tailwind CSS, Radix, Recharts, Lucide и Zod. Полный запуск проекта описан в [корневом README](../README.md).

## Запуск отдельно

Из этой папки: `npm ci`, скопировать `.env.example` в `.env.local`, `npm run dev`.
Пример конфигурации включает live API на http://127.0.0.1:8000. Backend должен быть запущен.
Без конфигурации приложение использует mock; произвольные планы в нём не рассчитываются, текст примера отмечен как шаблон.

## Страницы

- `/`: вход, правила учебной симуляции.
- `/simulator`: пять районов, каталог 14 мер, бюджет, предварительные показатели, AI-советник.
- `/results`: финальный Score, районы и индикаторы, вклады, AI-анализ, одна замена, отчёт Markdown, JSON и сохранение плана.
- `/compare`: два сохранённых плана, различия решений и показателей, AI-объяснение различий.

Расчёты выполняются только backend. Все HTTP-запросы находятся в `lib/api.ts`, ответы проверяются Zod. Изменение плана проходит серверную валидацию; после замены нужен повторный finalize. AI-ошибка не удаляет числа.

Схема районов иллюстративная. До 12 сценариев хранятся в localStorage; серверного хранилища и авторизации нет.

## Проверки

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

Для production после сборки: `npm run start`. Переменные `NEXT_PUBLIC_*` встраиваются при сборке, поэтому после их изменения нужна новая сборка. Ключи AI в frontend не передаются.
