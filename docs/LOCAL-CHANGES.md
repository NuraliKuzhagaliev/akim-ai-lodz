# Локальная исправленная сборка — 23.09.2026

## Основа

GitHub: BAITC-Hacks/hack-921839cc-lodz-polska, интегрированная ветка feature/simulation, коммит `57bf030684a5883ed27d16d24933ab1e27593922`.
На момент чтения main содержал только frontend и документацию; для полноценного приложения использована интегрированная ветка. Все 117 исходных файлов сверены с Git blob SHA. История Git и секреты в локальную сборку не переносились. В GitHub ничего не публиковалось.

## Изменения

- Добавлен POST /api/ai/compare: повторная финализация обоих планов, серверные разницы, структурированный AI-ответ и идентификаторы проверенных результатов. Ошибочный план не вызывает AI. Разницы десятичных оценок не содержат артефактов двоичного вычитания.
- Подключены советник для неполного плана, AI-сравнение сохранённых планов и просмотр/скачивание краткого Markdown-отчёта.
- Предложение советника показывается только для соответствующего состояния плана; добавление повторно валидируется. Отчёт проверяется на соответствие решениям, Score и бюджету.
- JSON/Markdown используют общий механизм скачивания с временной ссылкой в документе.
- Пример конфигурации frontend включает live и AI-сравнение. CORS в Compose теперь настраивается окружением.
- Добавлены совместный Compose для двух сервисов, Dockerfile frontend, START.cmd и scripts/start.py. Первый локальный запуск устанавливает зависимости, сохраняет существующие конфигурации, согласует порты/API/CORS.
- Обновлены README и актуальные контракты, OpenAPI, добавлены карта требований и копии четырёх исходных PDF.
- Формулы, организаторский каталог, веса, ограничения и синергии не изменены.
- Устранено влияние запоздавших загрузок на текущее состояние: повторная загрузка города не сохраняет устаревшую ошибку. При восстановлении результата из браузера сверяются версия модели и checksum текущего датасета.

## Что проверка не подтверждает

- Внешний AI не вызывался: действующий ключ в этой среде не настроен. Модель, права аккаунта, квоты и сетевую доступность проверяет оператор реальным запросом.
- Docker не установлен; запуск контейнеров и публичное облачное развёртывание не проверены.
- Встроенный браузер выполнил нажатие JSON, но не вернул событие download. Markdown-отчёт и его кнопка отображаются; сохранение файлов средствами обычного браузера требует отдельной проверки пользователем. Код экспорта не зависит от AI для JSON.
- Локальные тесты не означают успешный GitHub Actions; эта сборка не публиковалась и CI для неё не запускался.
- Проверки подтверждают перечисленные сценарии, но не являются гарантией отсутствия любых ошибок.

## Комплект

Папка на текущем компьютере содержит установленное локальное окружение; START.cmd использует его, если оно существует.
ZIP содержит только исходники, lock-файл, конфигурационные примеры, тесты, документацию и PDF. Он не содержит .venv, node_modules, .next, ключей, тестового сервера или истории Git. При переносе следуйте README и установите Python 3.12 / Node.js 22.20+.
