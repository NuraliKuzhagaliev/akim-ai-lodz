# Сверка требований с локальной сборкой

Источники: четыре предоставленных PDF — краткое ТЗ HackAlem, «Датасет районов», «план проекта», «четкое разделение участников».
Копии исходников: [ТЗ](specs/hackalem-brief.pdf), [датасет](specs/district-dataset.pdf), [план](specs/project-plan.pdf), [роли](specs/team-roles.pdf).
Сверка выполнена 23.09.2026. Последний подробный документ о ролях и существующая интеграция определяют стек Next.js + FastAPI; раннее предложение Vite/Fastify из плана не переносилось.

| Требование | Реализация / проверка |
| --- | --- |
| Пять районов и десять индикаторов | shared/districts.json; каталог сервера, схема и таблица UI |
| 14 мер, стоимость, охват, задержки | shared/measures.json; карточки каталога |
| 100 бюджета, ровно 5 уникальных мер | app/simulation/validation.py; finalize |
| Максимум 2 одного направления, минимум 3 направления | Валидатор и tests/test_validation.py |
| Совместимость и синергии из PDF | shared/model.json; расчётный движок и тесты |
| Горизонт 8 кварталов, точные расчёты | Fraction в движке; округление только в ответе |
| Сумма эффектов до clamp 0–100, независимость порядка | tests/test_engine.py и test_boundaries.py |
| Общий Score, слабейший район, критические значения | service.py; итог и панель равенства |
| AI strengths / risks / tradeoffs / recommendations | Проверенные сервером факты, структурированный ответ |
| Не доверять клиентским числам | AI-адаптеры пересчитывают сценарии; отрицательные API-тесты |
| Советник для незавершённого плана | /api/ai/advice + AdvicePanel; предложения отдельно валидируются |
| Сохранение и сравнение планов | localStorage и /compare |
| Улучшение одной заменой | /api/recommend, показ потерь и повторная проверка применения |
| «Защити решение», AI-сравнение | /api/ai/compare; два проверенных набора, проверка принадлежности ответа |
| Краткий отчёт | /api/report/executive-brief; просмотр и скачивание Markdown |
| Сценарий для жюри и запуск | README.md, START.cmd, scripts/start.py |

## Контрольные значения

База **52.55768**; пример M7/Нура + M8/Нура + M10/Нура + M12/город + M5/Сарыарка — **56.54307**, стоимость **95**.
Замена M5/Сарыарка на M3/Нура — **57.20556**, стоимость **100**.

## Границы

Общий рейтинг команд, неожиданные события и готовая презентация PPT/PDF — опциональные пункты краткого ТЗ; не реализованы.
Markdown-отчёт доступен, но это не PDF-генератор.
Настоящий AI требует серверного ключа; отсутствие ключа явно показывается и не блокирует математику.
Данные синтетические; приложение не подключено к городским реестрам. Поиск одной замены не является глобальным оптимизатором.
